## 七、注意事项（这些坑已经踩过，别重复）

- **win10-gs 的 Agent 文件有 `System` 属性**，`Copy-Item` 覆盖会被拒绝访问。正确做法：先 `Rename-Item` 旧文件，再 `Copy-Item` 新文件，然后删旧文件。
- **停服务后进程可能还在**（SCM failure actions 5 秒后拉起）。替换前要先 `sc failure ... actions= ""` 清空失败动作，替换完再恢复 `restart/5000/restart/5000/restart/5000`。
- **计划任务 `/sc once` 到点还会再跑一次**，用完必须 `schtasks /delete`。
- **SYSTEM 跑计划任务时**要显式设 `PUB_CACHE` 和 `NUGET_PACKAGES`（32 位 MSBuild 会把 `system32\config\systemprofile` 重定向到 SysWOW64，导致 WiX 扩展被静默跳过）。
- **rd-api 的 stream-broker 是 Go 写的独立进程**（`127.0.0.1:8787`），复用它的 `reserve/commit/remove` 连接管理与 `authorizeAdmin` 鉴权；**不要**把终端 I/O 塞进 PHP-FPM（池子只有 12 个 worker）。
- **现有 nginx 的两个 SSE location 显式清空了 `Connection` 头**，加 WS 必须新写一个 location，不能改现有的。
- **`UpdateLogPanel.vue` 已有 SSE 消费**，改动它时不要破坏 `withCredentials` + nginx 透传 `Cookie` 这条链。
